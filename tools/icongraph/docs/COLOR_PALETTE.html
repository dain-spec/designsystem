11단 컬러 팔레트

Gray 의 CIELAB 명도 계단을 기준으로 8색을 0–900 11단으로 맞췄다. 인디고·퍼플은 계단에 되맞췄고, 옐로·브라운은 색이 무너지므로 예외로 둔다. 스와치를 누르면 hex 가 복사된다.

옐로와 브라운은 단계 번호가 다른 밝기를 가리킨다

옐로 — 채도 최고점이 밝은 쪽에 있어 Gray 계단에 앉히면 겨자색이 된다
브라운 — 브라운은 어두운 오렌지다. 밝게 올리면 살구색이 되어 브라운으로 읽히지 않는다

읽는 법 — 옐로 400 은 다른 색의 200 정도 밝기다. 브라운 400 은 다른 색의 600 정도다. 같은 무게로 보이게 하려면 이 표대로 짝지어 쓴다.

브라운 다크단은 자체 추세를 잇는다브라운 600(#803017)은 이미 Gray 700 의 밝기(L* 31)에 있다. 다크단을 Gray 계단에 맞추면 600 과 같은 색이 되므로, 브라운만 자체 간격으로 연장했다. 옐로는 반대로 600 이 L* 61 라 여유가 있어 Gray 계단을 그대로 쓴다.
